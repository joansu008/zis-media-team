# Common rules

- Preserve the user's actual goal and platform constraints.
- Use project-relative paths in committed material; machine paths belong only in local environment configuration.
- Record state and handoffs as JSON. Do not depend on long chat history.
- Do not claim an artifact exists until its file exists and can be checked.
- Keep source evidence/ranges when available. Mark uncertainty rather than inventing facts.
- External writes, publishing, destructive changes, and sibling-repository edits require explicit permission.
